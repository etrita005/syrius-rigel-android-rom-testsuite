# 系统配置写入记录

> 用途：记录 MDM 功能实现中**向系统配置文件写入的内容**（应用侧声明、DPM 策略状态、Settings 键等），供 ROM 侧与部署排查对照。
> 规则：每批次功能实现若涉及系统配置文件写入，须在本文件同步描述写入内容（见项目根 `CLAUDE.md` "System Configuration File Writes"）。

## 1. device_admin.xml（Launcher 内嵌声明，系统 DPM 消费）

**文件**：`app/src/main/res/xml/device_admin.xml`（打包进 Launcher APK，`AndroidManifest.xml` 的 AdminReceiver 声明 `android.app.device_admin` 引用）

**当前内容（2026-08-04）**：

```xml
<device-admin xmlns:android="http://schemas.android.com/apk/res/android">
    <uses-policies>
        <wipe-data />
        <expire-password />
        <limit-password />
        <disable-camera />
    </uses-policies>
</device-admin>
```

| 声明 | 供哪些功能使用 | 说明 |
|---|---|---|
| `<wipe-data/>` | ASR-0123 执行恢复出厂设置（`dpm.wipeData`） | 既有声明 |
| `<expire-password/>` | ASR-0365 密码更改宽限期（`setPasswordExpirationTimeout`） | 2026-08-04 新增；DPM 校验 uses-policy，缺失时调用报 "did not specify uses-policy for: expire-password" |
| `<limit-password/>` | ASR-0363 连续数字序列上限（`setPasswordQuality`/`setPasswordMinimumLength` 组合）；既有密码质量模式 `setPasswordMode` | 既有声明 |
| `<disable-camera/>` | ASR-0207 禁用摄像头（`dpm.setCameraDisabled`） | 既有声明（摄像头批次新增） |

**部署注意**：本 ROM 的 DevicePolicyManagerService 在框架启动时缓存 admin 的 uses-policy 集，**仅重装 APK 不生效**，修改本文件后须软重启 framework（`adb shell stop && adb shell start`）方可生效（2026-08-04 ASR-0365 实测；ASR-0207 摄像头批次同流程）。

## 2. DPM 策略状态（/data/system/device_policies.xml）

经 `DevicePolicyManager` 公开接口写入，由框架持久化到 `device_policies.xml`（应用不直接写文件）。`dumpsys device_policy` 可对照。

| 策略字段 | 写入接口 | 功能 |
|---|---|---|
| `passwordQuality`（如 0x0=UNSPECIFIED、0x20000=NUMERIC、0x50000=ALPHANUMERIC） | `dpm.setPasswordQuality` | ASR-0363（按 limit 映射） |
| `minimumPasswordLength` | `dpm.setPasswordMinimumLength` | ASR-0363（按 limit 映射，0/4/6/8） |
| `strongAuthUnlockTimeout`（ms） | `dpm.setRequiredStrongAuthTimeout` | ASR-0359（写后读回核对；本 ROM 实测：非 0 且 <3600000 的值被 ROM 提升至 3600000，0 保持） |
| `passwordExpirationTimeout` / `passwordExpirationDate`（ms） | `dpm.setPasswordExpirationTimeout` | ASR-0365（0=永不过期；自最近一次设置密码时刻起算；设置超时即产生到期时刻） |
| 备份服务开关（BackupManagerService enabled 状态，`dumpsys backup` 可对照） | `dpm.setBackupServiceEnabled` / `isBackupServiceEnabled` | ASR-0124（禁用/启用系统备份；API 31+；**DISALLOW_BACKUP 已被 AOSP 13 移出有效用户限制集合，真机实测 addUserRestriction 静默丢弃，故改用本接口**；无需 uses-policy 声明） |
| 用户限制 `no_modify_accounts`（UserManager.DISALLOW_MODIFY_ACCOUNTS） | `dpm.addUserRestriction` / `clearUserRestriction` | ASR-0129（禁用/启用账户增删；配合 AccountManager.removeAccountExplicitly 清除存量账户；**无需** uses-policy 声明） |
| 截屏禁用（`disableScreenCapture` / `Screen capture disallowed users`，`dumpsys device_policy` 可对照） | `dpm.setScreenCaptureDisabled` / `getScreenCaptureDisabled` | ASR-0185/0186（禁用/启用系统与手动截屏；FLAG_SECURE 阻断物理键/系统截屏与 adb screencap，真机实测禁用时 screencap 输出 0 字节；**无需** uses-policy 声明，无需重启 framework） |
| 系统更新策略（`device_owner_2.xml` 的 SystemUpdatePolicy 段 / `dumpsys device_policy` "System Update Policy" 行） | `dpm.setSystemUpdatePolicy` / `getSystemUpdatePolicy` | ASR-0444（禁用在线 FOTA=POSTPONE 延期安装，启用=null 清除策略回自动；device owner 专属，**无需** uses-policy 声明；**本 ROM 为 fork 版 SystemUpdatePolicy，类型常量与 AOSP 不同（TYPE_POSTPONE=3，AOSP 标准为 2，经 framework 反编译核验），Launcher 引擎运行时反射解析常量**） |
| Wi-Fi SSID 策略（SSID allowlist/denylist，`getWifiSsidPolicy` 读回对照；本 ROM fork 版：`WifiSsidPolicy(int, Set<WifiSsid>)`、`WIFI_SSID_POLICY_TYPE_ALLOWLIST=0`、set/get 无 ComponentName 参数） | `dpm.setWifiSsidPolicy` / `getWifiSsidPolicy` | ASR-0152（企业 WiFi 白名单；引擎写后读回核对 + 主动断开不符合条件网络；本 ROM 框架在策略变更时断开不合格网络（logcat "disconnect admin restricted network"）并经 `isAdminRestrictedNetwork` 拦截 enableNetwork/connect/自动加入；**无需** uses-policy 声明，无需重启 framework） |
| 最低 Wi-Fi 安全级别（`mWifiMinimumSecurityLevel`，`dumpsys device_policy` 可对照；本 ROM fork 常量 0=OPEN 1=PERSONAL 2=ENTERPRISE_EAP 3=ENTERPRISE_192） | `dpm.setMinimumRequiredWifiSecurityLevel` / `getMinimumRequiredWifiSecurityLevel`（无 ComponentName 参数） | ASR-0158（设置最低安全级别；写后读回核对；本 ROM 框架在级别提升时断开低于级别的已连接网络并拦截连接/自动加入；**无需** uses-policy 声明，无需重启 framework） |
| 用户限制 `no_config_wifi`（UserManager.DISALLOW_CONFIG_WIFI） | `dpm.addUserRestriction` / `clearUserRestriction` | ASR-0141/0150/0155（禁止用户修改 AP 配置/编辑 WLAN 设置；生效后 Settings WLAN 页显示 "Blocked by your IT admin" 无法进入；**无需** uses-policy 声明。注：ASR-0150 备选的 `Settings.Global.wifi_device_owner_configs_lockdown` 经真机核验本 ROM 仅保护 DO 创建的配置、不保护用户配置，未采用） |
| 用户限制 `no_add_wifi_config`（UserManager.DISALLOW_ADD_WIFI_CONFIG） | `dpm.addUserRestriction` / `clearUserRestriction` | ASR-0153（禁止手动添加网络；生效后 Settings WLAN 页非当前网络行 "Not allowed by your organization" 且不可点击；**无需** uses-policy 声明） |
| 用户限制 `no_wifi_direct`（UserManager.DISALLOW_WIFI_DIRECT） | `dpm.addUserRestriction` / `clearUserRestriction` | ASR-0160（禁止 WLAN 直连；**无需** uses-policy 声明） |
| 用户限制 `no_config_tethering`（UserManager.DISALLOW_CONFIG_TETHERING） | `dpm.addUserRestriction` / `clearUserRestriction` | ASR-0168（禁止修改热点配置）/ ASR-0400 / ASR-0405（禁止用户修改 USB / 蓝牙共享 Settings，AOSP 13 无按类型区分的限制，整页生效，三者共用同一引擎；**无需** uses-policy 声明） |

**本 ROM DPM 行为注意**：① `setPasswordMinimumLength` 在 quality=UNSPECIFIED 时被 ROM 拒绝（抛 "password quality should be at least 131072"，且先写入后校验），引擎按方向调整写入顺序（恢复 UNSPECIFIED 时先降长度再降质量）；② admin uses-policy 集在框架启动时缓存，`device_admin.xml` 变更后仅重装 APK 不生效，须重启 framework/整机。

**策略激活对既有凭据的影响（部署注意事项）**：① 严格密码策略（如 limit≤4）会使既有弱凭据不满足策略——锁屏强制交互改密、`locksettings clear` 被拒（"Weak credential type"），恢复须远程下发 `SetConsecutiveDigitsLimit limit=0`（或本机交互改密）；② 密码宽限期（ASR-0365）的到期时刻以**策略设置时刻**起算（非下次改密），设备上已存在设置早于 timeout 的凭据时，下一次解锁即进入强制改密流程；恢复命令 `SetPasswordExpirationTimeout timeoutMs=0`。业务部署建议顺序：先设置/更新密码，再设置宽限期。
