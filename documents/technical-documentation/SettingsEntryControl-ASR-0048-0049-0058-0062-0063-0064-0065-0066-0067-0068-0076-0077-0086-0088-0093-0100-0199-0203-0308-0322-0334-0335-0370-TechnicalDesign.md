# 入口/设置锁定（SettingsEntryControl）技术设计文档

| ASR-0334 | 系统语言 | 获取/设置是否允许系统语言切换 | 语言选择页组件禁用 + SetLanguage 命令门禁（引擎级拒绝） |
| ASR-0335 | 系统语言 | 获取/设置是否允许用户修改系统语言切换 | 语言选择页组件禁用（用户入口级，MDM SetLanguage 不受限） |
| ASR-0370 | 扬声器 | 查询/设置是否禁用扬声器 | 音量流清零 + setSpeakerphoneOn(false) + 10s 周期校正；启用恢复锁定前音量 |

**归属**：全部 20 条为「Launcher（MDM）」；页面锁定统一使用公开 `PackageManager.setComponentEnabledSetting`（CHANGE_COMPONENT_ENABLED_STATE 签名权限，平台签名 uid=1000 自动授予）；可见性策略使用 device owner 公开 `setApplicationHidden`；值锁定使用 Settings 直写 + ContentObserver（WRITE_SECURE_SETTINGS/全局写权限，uid=1000 平台签名持有）；扬声器使用公开 `AudioManager`；**无需 @SystemApi/@hide、无需 ROM 改动、无需新增 manifest 权限**。

**基线**：目标平台 Android 13（API 33）userdebug，平台签名 + device owner 部署；bootloader 锁定。本 ROM Settings 包为 MTK fork（`/system/system_ext/priv-app/MtkSettings`），PermissionController 位于 APEX（`com.android.permissioncontroller`，版本 TP1A.220624.014）。

## 2. 技术选型与可行性核验

### 2.1 目标组件清单（真机/APK manifest 核验，2026-08-07）

| 需求 | 目标组件（flatten 短名） | 核验方式 |
|---|---|---|
| ASR-0048 | `com.android.permissioncontroller/.permission.ui.ManagePermissionsActivity` + `...Trampoline` | PermissionController APK manifest 抽取 |
| ASR-0049 | `com.android.permissioncontroller/.permission.ui.legacy.AppPermissionActivity` | 同上 |
| ASR-0058 | `com.android.settings/.Settings$NotificationAppListActivity` + `...$AppNotificationSettingsActivity` | MtkSettings APK manifest 抽取 |
| ASR-0063 | `com.android.settings/.Settings$ConfigureNotificationSettingsActivity` + `...$AppNotificationSettingsActivity` | 同上；`NOTIFICATION_SETTINGS` action 真机解析命中前者 |
| ASR-0066 | `com.android.settings/.Settings$ManageApplicationsActivity` + `com.android.settings/.applications.ManageApplications`（alias，`MANAGE_ALL_APPLICATIONS_SETTINGS` 真机解析命中） | 真机 `cmd package resolve-activity` |
| ASR-0077 | `com.android.settings/.Settings$AccessibilitySettingsActivity`（`ACCESSIBILITY_SETTINGS` 解析命中） | 真机 resolve |
| ASR-0086/0088/0093/0100 | `com.android.permissioncontroller/.role.ui.RequestRoleActivity` + `...DefaultAppActivity`（Android 13 默认应用修改统一经 RoleManager 角色请求流程，`android.app.role.action.REQUEST_ROLE` 真机解析命中 RequestRoleActivity）；ASR-0093 另含 `com.android.settings/.Settings$ManageAssistActivity` | 真机 resolve + PC manifest |
| ASR-0199 | `com.android.settings/.Settings$UsbDetailsActivity` | MtkSettings manifest |
| ASR-0308 | `com.android.settings/.Settings$ApnSettingsActivity`（`APN_SETTINGS` 解析命中） | 真机 resolve |
| ASR-0334/0335 | `com.android.settings/.Settings$LocalePickerActivity`（`LOCALE_SETTINGS` 解析命中）+ `com.android.settings/.localepicker.LocalePickerWithRegionActivity` | 真机 resolve + manifest |

**关键核验结论**：

- **Android 13 无按包禁用设置入口的能力**：ASR-0049 的"指定应用权限页面"是所有应用共用的组件（AppPermissionActivity），不存在 per-package 入口禁用——本设计按"页面入口级"落地：禁用该组件即任何应用的权限页均不可进入，`packageName` 参数仅用于安装校验并在结果回显（如实记录于边界表）；
- **默认应用修改统一走角色选择器**：短信/拨号/Assistant/浏览器默认应用修改在 Android 13 均经 `RoleManager` 请求流程解析到 PermissionController 的 RequestRoleActivity（真机 resolve 核验），四个需求共用同一组件集；**无按角色禁用入口的能力**，四个标志独立持久化、共用组件状态派生（任一锁开启即禁用、全部关闭才恢复）；
- **本 ROM 隐藏应用即从设置应用列表消失**：`setApplicationHidden` 隐藏的应用不出现在 Settings "All apps" 列表（uiautomator dump 真机核验），且**从用户视角的 `getInstalledApplications` 中消失**（`pm list packages` 不含隐藏包，`-u` 含）——应用管理页面白/黑名单策略的生效基础；同时这是恢复路径枚举必须带 `MATCH_UNINSTALLED_PACKAGES` 的原因；
- **⚠️ 隐藏运行中的系统 provider 会击垮 framework**：白名单模式初版按"隐藏全部非白名单应用"实现，真机验证时隐藏 `com.android.providers.telephony`（进程 com.android.phone 承载）导致 VcnManagementService 的 PACKAGE_REMOVED 广播处理器在启动早期查询 telephony provider 抛 SecurityException，system_server 崩溃循环约 20 分钟（VcnManagementService 处理器未捕获该异常的 ROM 缺陷被触发）。修复：**白名单模式仅过滤第三方应用**（FLAG_SYSTEM 系统应用始终可见），另有显式保护名单 + 关键前缀保护（providers/phone/bluetooth/nfc/cellbroadcast/mediatek）；
- **本 ROM 通知状态为权限驱动**：声明 POST_NOTIFICATIONS 的应用其通知开关状态由运行时权限（可被 SYSTEM_FIXED 撤销）决定，AppOps 仅带默认 allow 值——ASR-0063 回滚与 Is 查询都必须走完整链路（强制通道 + 权限状态联合判定），详见 2.3。

### 2.2 页面锁定机制

统一采用公开 `PackageManager.setComponentEnabledSetting(ComponentName, COMPONENT_ENABLED_STATE_DISABLED/ENABLED, DONT_KILL_APP)`：禁用后对应 Settings action 解析失效（`cmd package resolve-activity` / testapp resolveActivity 均返回 unresolved，真机闭环核验），恢复时显式置 ENABLED（非 DEFAULT，读回确定性）。写后逐个 `getComponentEnabledSetting` 读回核对（`state`/`stateName`/`enabled` 回显；enabled=非 DISABLED/DISABLED_USER 即有效启用，DEFAULT 视为 manifest 默认启用）。组件状态由 PMS 持久化（package-restrictions.xml），**整机重启保持，无需 Launcher 侧持久化与重新下发**。

### 2.3 值锁定/回滚引擎（ASR-0062/0063/0064/0065/0203/0322）

统一模式：**锁定标志 + 锁定值持久化（SharedPreferences）+ 观察者/周期校正器回滚**，进程重启（ApiService.onCreate）与开机（BootCompletedReceiver）经 sync 重新武装：

- **ASR-0062（通知白名单防关闭）**：`AppOpsManager.startWatchingMode("android:post_notification", null, listener)`（公开 API）监听全包通知状态变化；白名单包（ASR-0054 名单）被用户关闭时**立即经完整链路重新开启**（完整链路=隐藏 NMS API 反射 → AppOps setMode → 权限 grant/revoke 兜底，绕过 AppOps 默认值早退，适配本 ROM 权限驱动模型）；另在锁开启/进程重启时对白名单整体校验一遍；
- **ASR-0063（禁止修改通知设置）**：通知设置页组件禁用（ConfigureNotificationSettings + AppNotificationSettings，`NOTIFICATION_SETTINGS`/`APP_NOTIFICATION_SETTINGS` action 解析失效）+ 同一 AppOps 观察者把任意包的用户改动回滚到 ASR-0054/0055 策略判定结果（`applyToPackageForced`——强制完整链路，避免 AppOps 默认 allow 早退掩盖权限态）；策略 mode=0 时观察者仅执行 0062 白名单保护分支；
- **ASR-0064（状态栏通知设置锁）**：锁定时把 ASR-0059 持久化状态（`status_bar_notifications_policy.disabled`）作为锁定值，10s 自续期校正器对比 `dumpsys statusbar` mDisabled1 位（0x20000），偏离即重新 `cmd statusbar send-disable-flag notification-icons|none`（uid=1000 平台签名可执行，STATUS_BAR 签名权限）；
- **ASR-0065（锁屏通知设置锁）**：ASR-0057 命令设置时把 lock_screen_show_notifications / lock_screen_allow_private_notifications 值持久化（`lockscreen_notifications_policy`）；锁开启后 Settings.Secure ContentObserver（300ms 防抖）把用户改动回滚到该锁定值；
- **ASR-0203（USB 调试设置锁）**：锁定时捕获 Settings.Global.adb_enabled 当前值；ContentObserver 回滚用户改动（如开发者选项里翻转 USB 调试开关）；
- **ASR-0322（飞行模式修改锁）**：锁定时捕获 airplane_mode_on 当前值；ContentObserver（300ms 防抖）+ 10s 校正器回滚用户改动（快捷开关/设置页翻转），与 ASR-0321 强制开启共用 10s 校正器（先判锁定值再判强制标志）。

### 2.4 应用管理页面可见性策略（ASR-0067/0068）

- 模式 0=关闭 / 1=白名单 / 2=黑名单，名单整体替换，SharedPreferences `settings_entry_policy` 持久化（`app_mgmt_mode`/`app_mgmt_whitelist`/`app_mgmt_blacklist`）；
- 应用：遍历 `getInstalledApplications(MATCH_UNINSTALLED_PACKAGES)`（**必须带该标志**——本 ROM 隐藏应用从用户视角枚举消失，否则恢复路径永远看不见已隐藏应用，开发期真机发现并修复），对每个非保护应用计算目标可见性并 `dpm.setApplicationHidden(admin, pkg, hidden)` 差异应用，写后 `isApplicationHidden` 读回核对，逐包 hidden/restored/failed 回显；
- **白名单模式只过滤第三方应用**（FLAG_SYSTEM 系统应用始终可见）；保护名单：Launcher/testapp/Settings/permissioncontroller/SystemUI/shell/providers.settings + 关键前缀（`com.android.providers.`、`com.android.phone`、`com.android.bluetooth`、`com.android.nfc`、`com.android.cellbroadcast`、`com.mediatek.`）——防止隐藏系统 provider 触发 VcnManagementService 崩溃循环（2.1 记录的事故）；
- 策略为系统运行时状态（非组件状态），进程重启/开机经 `syncPolicy` 重新下发；
- **副作用如实记录**：隐藏应用同时从 Launcher 应用列表消失（`setApplicationHidden` 的用户级语义），应用管理页白名单与"隐藏应用"需求（ASR-0018/0024 引擎）同机制可叠加。

### 2.5 扬声器禁用（ASR-0370）

- 禁用：捕获 6 条音频流（alarm/music/ring/notification/system/voice_call）当前音量与 `isSpeakerphoneOn` 状态 → 全部置 0 + `setSpeakerphoneOn(false)`（对照表规划的近似实现）→ 10s 校正器持续归零/强制听筒路由（用户调音量被还原）；
- 启用：恢复锁定前音量与扬声器状态；
- 标志持久化 `speaker_policy`，进程重启/开机 `syncSpeakerDisabled` 重新武装。

### 2.6 已开启辅助功能列表（ASR-0076）

复用 AccessibilityServicePolicyManager（ASR-0074/0075 批次）的 `enabledServices` 解析（Settings.Secure.enabled_accessibility_services 冒号分隔组件名，统一规范化短名）+ `accessibility_enabled` 总开关 + 已安装服务列表（getInstalledAccessibilityServiceList），新增专用查询命令 GetEnabledAccessibilityServices。

## 5. 执行逻辑

### 5.1 页面锁（以 ASR-0048 为例，其余同构）

```
1. 缺参/非法参数 → 结构化 error，不 crash
2. 逐个目标组件 setComponentEnabledSetting(目标态, DONT_KILL_APP)
3. 逐个 getComponentEnabledSetting 读回，matches = readBack == target
4. 返回 {locked, success, components:[{component, state, success, enabled}]}
5. 组件状态 PMS 持久化，重启保持，无需 sync
```

### 5.2 默认应用共享锁（ASR-0086/0088/0093/0100）

```
1. 持久化本需求标志（sms/dialer/assistant/browser 独立键）
2. anyLocked = 四标志取或；组件目标态 = !anyLocked
3. 对 RequestRoleActivity + DefaultAppActivity 应用目标态并读回
4. ASR-0093 额外处理 Settings$ManageAssistActivity
5. 返回 {locked, rolePickerEnabled, components}
```

### 5.3 回滚引擎（ASR-0062/0063/0064/0065/0203/0322）

```
1. 锁开启：捕获/持久化锁定值（0064 读 ASR-0059 标志、0065 读 ASR-0057 持久化值、0203 读 adb_enabled、0322 读 airplane_mode_on）
2. 注册观察者/校正器（进程级一次，ApiService.onCreate/BootCompletedReceiver 重新武装）：
   - 0062/0063：AppOps post_notification 观察者 → 0062 分支保护白名单、0063 分支 applyToPackageForced
   - 0064：10s 自续期校正器 → dumpsys mDisabled1 对照 0x20000 → cmd statusbar send-disable-flag
   - 0065：lock_screen_show_notifications/private 观察者（300ms 防抖）→ 写回持久化值
   - 0203：adb_enabled 观察者（300ms 防抖）→ 写回锁定值
   - 0322：airplane_mode_on 观察者（300ms 防抖）+ 10s 校正器 → 写回锁定值并广播 ACTION_AIRPLANE_MODE_CHANGED
3. 锁关闭：清标志，观察者保持注册但不再动作
```

### 5.4 应用管理可见性策略（ASR-0067/0068）

```
1. 读 mode + 名单（SharedPreferences）
2. 枚举 getInstalledApplications(MATCH_UNINSTALLED_PACKAGES)
3. 每包：保护判定（显式名单 + 关键前缀 + FLAG_SYSTEM（白名单模式））→ 计算 wantHidden → isApplicationHidden 读当前 → 差异应用 setApplicationHidden(admin, pkg, wantHidden) → 读回核对
4. 返回 {mode, hidden[], restored[], skipped[]}
```

### 5.5 扬声器禁用（ASR-0370）

```
1. 禁用：捕获 6 流音量 + isSpeakerphoneOn → 持久化 → 全部置 0 + setSpeakerphoneOn(false) → 启动 10s 校正器
2. 校正器：标志开启时持续归零 + setSpeakerphoneOn(false)
3. 启用：恢复持久化音量 + speakerphoneOn 状态 → 停校正器
```

## 7. 边界与异常处理

| 场景 | 处理 |
|---|---|
| 缺参/布尔参数经广播通道为字符串 | paramBoolean 统一解析（"true"/"false" 字符串与 Boolean 均接受） |
| ASR-0049 目标包未安装 | {success:false, error:"package not installed: <pkg>"}，不写组件 |
| 页面组件写失败/读回不一致 | 该组件 {success:false, error}，其余组件继续，整体 success=false |
| **隐藏运行中系统 provider（白名单模式）** | 白名单模式仅过滤第三方应用 + 保护名单/关键前缀；真机事故记录：初版隐藏 com.android.providers.telephony 触发本 ROM VcnManagementService 崩溃循环（其 PACKAGE_REMOVED 处理器未捕获 telephony provider 查询异常），恢复手段=删除 packages.xml 重建包注册表 + 重新设置 device owner（2026-08-07 实测，见真机验证记录） |
| 恢复路径看不到已隐藏应用 | getInstalledApplications 带 MATCH_UNINSTALLED_PACKAGES（本 ROM 隐藏应用从用户枚举消失，开发期真机发现并修复） |
| 通知状态为权限驱动（本 ROM） | 0062/0063 回滚走完整链路（隐藏 NMS API → AppOps → 权限兜底），Is 查询联合权限状态判定；AppOps 默认 allow 不能作为"已开启"证据 |
| 状态栏校正器锁后开启 | 校正器自续期（不依赖锁开启时刻），锁随时可开启 |
| 飞行模式锁定期间用户翻转 | 观察者 300ms 防抖 + 10s 校正器双保险回滚，回滚走完整两步（写值 + ACTION_AIRPLANE_MODE_CHANGED 广播） |
| 扬声器禁用期间用户调音量 | 10s 校正器归零；启用恢复锁定前音量（锁定前未捕获的流不恢复） |
| testapp 被 force-stop 后广播丢失 | 本 ROM MTK DuraSpeed 把 force-stop 应用加入静态 receiver 抑制名单（AMSS 日志 isSkip=true），测试期间以 root kill 替代 force-stop（2026-08-05 无障碍批次已有记录）；send_test_command.sh 增加 --include-stopped-packages |
| ASR-0086/0088/0093/0100 共享组件 | 任一锁开启即禁用角色选择器（无按角色禁用能力，如实记录）；四个标志独立持久化与查询 |
