# WLAN 强管控（ASR-0150/0152/0153/0155/0158/0160/0168）测试用例设计文档

## 1. 前置条件

- 设备：Android 13（API 33）userdebug ROM，已部署平台签名 Launcher（`com.hmdm.launcher`，uid=1000）并设为 device owner；testapp（`com.hmdm.testapp`）已安装（**本批次起为平台签名部署**，见设计文档第 6 节；重装须先经 `SetUninstallBlocked canUninstall=true` 解除卸载锁）；
- 部署准备：`adb root`、屏幕常亮（`svc power stayon true`）；
- 测试通道：`./send_test_command.sh <event> key=value ...`（IPC 与 UI 按钮等效，同一 `TestActions.execute()` 引擎）；也可在 testapp UI 的 "WLAN control" 页面点按对应按钮；
- 对照命令：`adb shell dumpsys user | grep -A5 -i restriction`（用户限制 "Effective restrictions" 段）、`adb shell dumpsys device_policy | grep -i mWifiMinimumSecurityLevel`（安全级别）、`adb shell cmd wifi status`（连接状态）、`adb shell cmd wifi list-networks`（已保存网络）、`adb shell logcat -d -s WifiService:V | grep restricted`（框架执行日志）、`adb shell settings get global wifi_device_owner_configs_lockdown`（备选方案残留键）；
- 已保存网络基线：`Syrius_Guest`（开放网，netId=0）可用且设备默认连接；另有 `syrius-4px`（wpa2）；
- 恢复基线（测试开始时记录、结束时恢复）：无 `no_config_wifi`/`no_add_wifi_config`/`no_wifi_direct`/`no_config_tethering` 用户限制、SSID 策略为空（policyType=-1）、`mWifiMinimumSecurityLevel=0`、设备重新连接 `Syrius_Guest`；
- 本 ROM 特性（2026-08-04 核验）：① SDK 为 fork 版（`WifiSsidPolicy` 用 `WifiSsid` 对象、ALLOWLIST=0、DPM 方法无 ComponentName 参数、安全级别常量 0~3=OPEN/PERSONAL/ENTERPRISE_EAP/ENTERPRISE_192）；② SSID 白名单与最低安全级别由框架在策略变更时断开不合格网络（logcat `disconnect admin restricted network`），并在 enableNetwork/connect/自动加入路径经 `isAdminRestrictedNetwork` 拦截（logcat `enableNetwork not allowed for admin restricted network Id=%`）；③ `WIFI_DEVICE_OWNER_CONFIGS_LOCKDOWN` 仅保护 DO 创建的配置、不保护用户配置（实测 lockdown=1 时平台签名非 DO 应用 addNetwork 仍成功），ASR-0150 经用户确认改用 `DISALLOW_CONFIG_WIFI`；④ `no_add_wifi_config` 生效时 Settings WLAN 页将非当前网络行标记 "Not allowed by your organization" 且 `enabled=false`（uiautomator 实测）。

## 3. 验证提示

- 结果查看：`./send_test_command.sh` 输出 `Broadcast completed: data=...` 与 logcat `HYX-TESTAPP-CMD` 行；
- 用户限制对照：`adb shell dumpsys user | grep -A5 -i restriction`（"Effective restrictions" 段；键名 no_config_wifi / no_add_wifi_config / no_wifi_direct / no_config_tethering）；
- 安全级别对照：`adb shell dumpsys device_policy | grep -i mWifiMinimumSecurityLevel`；
- 连接状态对照：`adb shell cmd wifi status`（"Wifi is connected to ..."）；已保存网络：`adb shell cmd wifi list-networks`（Syrius_Guest netId=0）；
- 框架执行日志：`adb shell logcat -d -s WifiService:V | grep restricted`（策略变更断开 `disconnect admin restricted network`；连接拦截 `enableNetwork not allowed for admin restricted network Id=%`）；
- 设置页验证：`adb shell am start -a android.settings.WIFI_SETTINGS` + `adb shell uiautomator dump /sdcard/ui.xml` + `grep -oE '(text|content-desc)="[^"]{2,}"'`（"Blocked by your IT admin" / "Not allowed by your organization" 及行节点 enabled 属性）；
- 平台签名 testapp 说明：本批次 testapp 改平台签名部署（CHANGE_WIFI_STATE 为纯签名权限，普通应用无法获得；WifiVerifier 需要）。其 addNetwork/enableNetwork 行为与 Settings（同为平台签名非 DO）等效；
- 数值参数说明：level 支持数值与数字字符串（`send_test_command.sh` 对负数/字符串透传，命令侧已兼容解析）；布尔参数 `true`/`false` 透传为 Boolean，其余字符串按 `Boolean.parseBoolean` 语义（与既有命令一致）。
