# 入口/设置锁定（SettingsEntryControl）测试用例设计文档

## 1. 前置条件

- 设备：Android 13（API 33）userdebug ROM，已部署平台签名 Launcher（`com.hmdm.launcher`，uid=1000）并设为 device owner；testapp（`com.hmdm.testapp`，平台签名部署）已安装；
- 测试通道：`./send_test_command.sh <event> key=value ...`（IPC 与 UI 按钮等效，同一 `TestActions.execute()` 引擎；UI 按钮位于 testapp "Entry/settings locking" 页面，按钮文本与用例组对应）；Launcher 命令也可经 `./send_test_broadcast.sh <event> key=value ...`（TestBroadcast）验证；
- 对照手段：`./send_test_command.sh GetEntriesLocal`（本地 resolve 各目标 Settings action + 15 个目标组件状态，与命令结果交叉核对）、`GetValuesLocal`（adb_enabled/airplane_mode_on/lock_screen_show_notifications/lock_screen_allow_private_notifications/enabled_accessibility_services/accessibility_enabled 原始值）、`GetAudioStateLocal`（6 条音频流音量 + isSpeakerphoneOn）、`adb shell dumpsys statusbar`（mDisabled1 位）、`adb shell dumpsys package <pkg> | grep hidden=`、`adb shell uiautomator dump`（Settings "All apps" 列表可视化）、`adb shell logcat -d -s HYX-MDM-APP`（引擎日志）；
- 恢复基线（每用例组结束后恢复）：所有锁/禁用标志置回关闭、通知白名单清空、锁屏通知设置恢复 1/1、应用管理模式 0 且名单清空、无障碍服务注销、音量恢复；
- 本 ROM 特性（2026-08-07 核验）：① Settings 包为 MTK fork（`/system/system_ext/priv-app/MtkSettings`），目标页面组件名经 APK manifest 抽取核验；PermissionController 位于 APEX（TP1A.220624.014）；② 页面组件禁用后对应 `android.settings.*` action 解析失效（`cmd package resolve-activity` 与 testapp resolveActivity 均 unresolved），恢复后解析恢复；③ **组件状态由 PMS 持久化（package-restrictions.xml），整机重启保持**；④ **本 ROM 隐藏应用（setApplicationHidden）即从 Settings "All apps" 列表消失，且从用户视角 `getInstalledApplications`/`pm list packages` 消失（`-u` 可见）**——可见性策略的生效基础，恢复路径枚举必须带 MATCH_UNINSTALLED_PACKAGES；⑤ ⚠️ **隐藏运行中的系统 provider 会触发本 ROM VcnManagementService 崩溃循环**（PACKAGE_REMOVED 处理器查询 telephony provider 抛 SecurityException 未捕获）——白名单模式仅过滤第三方应用（FLAG_SYSTEM 系统应用始终可见）+ 保护名单/关键前缀；⑥ **本 ROM 通知状态为权限驱动**（POST_NOTIFICATIONS 运行时权限，AppOps 仅默认 allow）——回滚走完整链路、Is 查询联合权限状态；⑦ testapp 被 force-stop 后其静态 receiver 广播被本 ROM MTK DuraSpeed 抑制（`onBeforeStartProcessForStaticReceiver ... isSkip=true`，重启设备清空）——测试期间以 root kill（`adb root` + `kill <pid>` + `adb unroot`）替代 force-stop；`send_test_command.sh` 已增加 `--include-stopped-packages`；⑧ 布尔参数经广播通道为字符串，命令层统一解析。

## 3. 硬件受限测试说明

本批次无硬件受限用例：全部机制（组件禁用、可见性策略、值锁定回滚、音量/扬声器状态）均可在本机（Android 13 userdebug，平台签名 + device owner）完整执行并已真机验收（2026-08-07）。记录两条环境相关注意点（非硬件受限）：

- **VcnManagementService 崩溃循环事故**（白名单模式隐藏系统 provider 触发，本 ROM VCN 处理器未捕获 telephony provider 查询异常）：恢复手段为删除 `/data/system/packages.xml` + `packages.list` 重建包注册表 + 重新设置 device owner；代码已修复（系统应用/关键前缀保护）。该事故发生在真机验证过程中，恢复后设备状态正常；
- **DuraSpeed 静态 receiver 抑制**（testapp 被 force-stop 后广播被 AMS 丢弃，`DuraSpeed: ... isSkip=true`）：测试期间以 root kill 替代 force-stop；`send_test_command.sh` 已加 `--include-stopped-packages`；重启设备可清空抑制名单。
