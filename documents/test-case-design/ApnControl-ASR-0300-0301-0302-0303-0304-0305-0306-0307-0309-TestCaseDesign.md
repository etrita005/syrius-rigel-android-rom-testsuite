# APN 管控（ASR-0300/0301/0302/0303/0304/0305/0306/0307/0309）测试用例设计文档

## 1. 前置条件

- 设备：Android 13（API 33）userdebug ROM，已部署平台签名 Launcher（`com.hmdm.launcher`，uid=1000）并设为 device owner，testapp（`com.hmdm.testapp`）已安装；
- 部署准备：`adb root`、屏幕常亮（`svc power stayon true`）；
- 测试通道：`./send_test_command.sh <event> key=value ...`；
- 测试素材：测试 APN（name=SyriusTest, apn=test.apn, mcc=460, mnc=01）；对照命令：`adb shell content query --uri content://telephony/carriers`（**shell 无 WRITE_APN_SETTINGS 权限，仅作参考**）；
- 恢复基线：测试 APN 全部删除、preferred=null、carriers 恢复默认（ResetApn）、DO 在位；
- 本 ROM 特性（2026-08-13 核验）：① carriers 表含 mcc=460 built-in 配置（无 SIM 可查）；② 命令的 name 参数按 name OR apn 匹配（本批次修正 3 处）；③ UpdateApn 的 updateValues 须含 mcc/mnc/numeric 等字段（TelephonyProvider 校验）；④ testapp JSON 输出经 ContentValues normalize（本批次修正）。

## 2. 测试用例表

### 2.1 ASR-0300/0301 查询（ApnList / GetApnConfigByName）

| 用例 | 步骤 | 预期结果 |
|---|---|---|
| TC-0300-01 列表 | `./send_test_command.sh ApnList` | 返回 carriers 列表（本机含 CBNET/CMNET/China Telecom/IMS/MMS 等 built-in） |
| TC-0301-01 按名查询 | `./send_test_command.sh GetApnConfigByName name=CMNET` | 返回 CMNET 完整配置（含 _id/apn/mcc/mnc）——2026-08-13 修正后 name 与 apn 值均可匹配 |
| TC-0301-02 按 apn 值查询 | `GetApnConfigByName name=cmnet` | 同样返回（apn 字段匹配） |
| TC-0301-03 无匹配 | `GetApnConfigByName name=nonexistent` | null（如实） |
| TC-0301-04 缺参 | `./send_test_command.sh GetApnConfigByName` | 返回 `missing parameter: name`，不 crash |

## 3. 硬件受限测试说明

- 本机（Android 13 / API 33 userdebug，平台签名 + device owner）可验证项（列表/查询/增删改/首选/重置）已全部执行通过（2026-08-13）。
- **本机无 SIM 卡**：APN 表操作不受影响（built-in carriers 可查、增删改首选/重置均闭环）；**APN 实际入网生效（连接运营商网络）需插卡设备**——插卡后执行 AddApn/SetPreferredApn 并观察实际数据连接即可完成最终验证。
- 本批次修复记录（设计文档第 2 节）：GetApnConfigByName/getApnIdByName/DeleteApn 的 name-apn 匹配与防御性读取、UpdateApn 参数读取与字段补齐、testapp ContentValues JSON 序列化。
