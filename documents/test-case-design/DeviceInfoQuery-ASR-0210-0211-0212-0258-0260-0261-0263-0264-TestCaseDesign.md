# 设备信息查询（ASR-0210/0211/0212/0258/0260/0261/0263/0264）测试用例设计文档

## 1. 前置条件

- 设备：Android 13（API 33）userdebug ROM，已部署平台签名 Launcher（`com.hmdm.launcher`，uid=1000）并设为 device owner，testapp（`com.hmdm.testapp`）已安装；
- 部署准备：`adb root`、屏幕常亮（`svc power stayon true`）；
- 测试通道：`./send_test_command.sh <event> key=value ...`；
- 对照命令：`adb devices`（序列号）、`adb shell getprop ro.product.model`、`adb shell dumpsys telephony.registry`（SIM 状态）、`adb shell cat /sys/class/net/wlan0/address`；
- 本机状态（2026-08-13/08-14）：**无 SIM 卡**（MCC/MNC/电话号码返回空串属预期）；无 CDMA（MEID 为 null 属预期）；**无 wlan0 sysfs 接口**（MAC 经 dpm 通道，需 WLAN 开启）；
- 恢复基线：WLAN 恢复会话基线（本机关闭）、DO 在位。

## 2. 测试用例表

### 2.1 ASR-0210/0212/0260/0261 设备信息（GetDeviceInfo）

| 用例 | 步骤 | 预期结果 |
|---|---|---|
| TC-0210-01 查询 | `./send_test_command.sh GetDeviceInfo` | RESULT 含 imei/imei2/meid/sn/model 五字段 |
| TC-0210-02 SN 对照 | 与 `adb devices` 序列号比对 | sn=P65246404D60624SC02 一致 |
| TC-0212-01 Model 对照 | 与 `getprop ro.product.model` 比对 | 一致（本机 "Android"） |
| TC-0260-01 IMEI | imei/imei2 字段 | 有效 15 位 IMEI（本机 354707100352113，双卡槽同号） |
| TC-0261-01 MEID | meid 字段 | 本机 null（无 CDMA，如实记录）；CDMA 设备返回 14 位 MEID |

### 2.2 ASR-0211 MAC 地址（GetMacAddress）

| 用例 | 步骤 | 预期结果 |
|---|---|---|
| TC-0211-01 WLAN 开启 | `./send_test_command.sh SetWifiOpen open=true`、等待就绪；`./send_test_command.sh GetMacAddress`；对照 `./send_test_command.sh GetWifiMac` | 返回真实 MAC（本机 00:08:22:a0:8b:03，dpm 回退通道；本 ROM 无 wlan0 sysfs） |
| TC-0211-02 WLAN 关闭 | `SetWifiOpen open=false`；`GetMacAddress` | null（dpm 通道关闭时不可用，2026-08-14 复核）；`cat /sys/class/net/wlan0/address` 不存在——如实记录 |
| TC-0211-03 恢复 | `SetWifiOpen open=false`（会话基线） | WLAN 关闭 |

### 2.3 ASR-0258/0263/0264 SIM 相关（GetSimTelephoneNumber / GetMcc / GetMnc）

| 用例 | 步骤 | 预期结果 |
|---|---|---|
| TC-0258-01 查询 | `./send_test_command.sh GetSimTelephoneNumber`；对照 `dumpsys telephony.registry` | 本机无 SIM：返回空串（如实）；插卡设备：返回线路 1 号码 |
| TC-0263-01 MCC | `./send_test_command.sh GetMcc` | 本机无 SIM：空串；插卡设备：3 位 MCC（如 460） |
| TC-0264-01 MNC | `./send_test_command.sh GetMnc` | 本机无 SIM：空串；插卡设备：2-3 位 MNC（如 01） |

### 2.4 恢复基线（测试结束）

| 用例 | 步骤 | 预期结果 |
|---|---|---|
| TC-B10-01 部署校验 | `adb shell dpm list-owners`；`GetConnectionStatus` | DO 在位；bound=true |

## 3. 硬件受限测试说明

- 本机（Android 13 / API 33 userdebug，平台签名 + device owner）可验证项（SN/Model/IMEI/MAC）已全部执行通过（2026-08-13/08-14）。
- **本机无 SIM 卡**：ASR-0258（SIM 电话号码）、ASR-0263（MCC）、ASR-0264（MNC）的命令与引擎已实现并真机验证无 SIM 返回空串的行为；**含 SIM 的取值验证（真实号码/MCC/MNC 数值）需插卡设备**——插卡后直接执行对应查询命令即可完成验证。
- **本机无 CDMA 能力**：ASR-0261 MEID 返回 null 属平台如实行为；CDMA 设备上可验证真实 MEID。
- **本 ROM 无 wlan0 sysfs 接口**：ASR-0211 经 dpm 回退通道（WLAN 开启时）验证通过；MAC 通道限制已如实记录于设计文档与 WlanStateControl 文档。
